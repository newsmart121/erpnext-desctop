# دليل البدء السريع - ERPNext Desktop

## خطوات التشغيل الأولى

### 1️⃣ التثبيت (مرة واحدة فقط)

**على Windows:**
- انقر مزدوجاً على `install.bat`

**أو يدوياً:**
```bash
cd erpnext-desktop-app
npm install
```

---

### 2️⃣ تشغيل التطبيق

**على Windows:**
- انقر مزدوجاً على `run.bat`

**أو يدوياً:**
```bash
npm start
```

---

### 3️⃣ بناء ملف التطبيق (.exe)

**على Windows:**
- انقر مزدوجاً على `build.bat`

**أو يدوياً:**
```bash
npm run build
```

سيتم إنشاء ملف التثبيت في مجلد `dist`.

---

## تخصيص رابط ERPNext

افتح الملف `src/main.js` وعدّل السطر:

```javascript
const erpNextURL = 'https://erp.frappe.cloud'; // غيّره إلى رابطك
```

### أمثلة:
- **سحابي:** `https://your-company.erpnext.com`
- **محلي:** `http://localhost:8000`
- **شبكة محلية:** `http://192.168.1.100:8000`

## المتطلبات الأساسية

✅ **Node.js** (الإصدار 18 أو أحدث)  
✅ **اتصال بالإنترنت** للوصول إلى خادم ERPNext  
✅ **مساحة تخزين** 500MB على الأقل للبناء  

---

## حل المشاكل الشائعة

### ❌ التطبيق لا يفتح
```bash
# أعد تثبيت المكتبات
npm install
```

### ❌ خطأ في الاتصال بـ ERPNext
- تحقق من رابط الخادم في `src/main.js`
- تأكد من أن خادم ERPNext يعمل

### ❌ فشل البناء (Build)
- تأكد من وجود مساحة كافية على القرص
- شغل الأمر كمسؤول (Administrator)
