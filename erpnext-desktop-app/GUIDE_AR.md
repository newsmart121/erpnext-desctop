# كيفية تحويل ERPNext إلى تطبيق سطح مكتب لنظام Windows

## نظرة عامة

تم إنشاء هذا المشروع لتحويل نظام ERPNext (نظام تخطيط موارد المؤسسات مفتوح المصدر) إلى تطبيق سطح مكتب يعمل على نظام التشغيل Windows باستخدام تقنية Electron.

## ما هو ERPNext؟

ERPNext هو نظام تخطيط موارد مؤسسات (ERP) متكامل ومفتوح المصدر يشمل:
- المحاسبة والمالية
- إدارة المخزون
- المبيعات والمشتريات
- إدارة الموارد البشرية
- إدارة المشاريع
- التصنيع
- وغيرها من الوحدات

## بنية التطبيق

```
erpnext-desktop-app/
├── package.json          # ملف تكوين المشروع والمكتبات
├── README.md             # دليل الاستخدام الشامل
├── INSTALL_WINDOWS.md    # دليل التثبيت السريع لنظام Windows
├── .gitignore           # ملفات Git المستبعدة
└── src/
    ├── main.js          # الكود الرئيسي للتطبيق (Electron)
    └── icon.ico         # أيقونة التطبيق (يجب إضافتها)
```

## كيف يعمل التطبيق؟

1. **Electron Framework**: يستخدم التطبيق إطار عمل Electron لإنشاء تطبيق سطح مكتب متعدد المنصات باستخدام تقنيات الويب (JavaScript, HTML, CSS).

2. **WebView**: التطبيق يعرض واجهة ERPNext داخل نافذة تطبيق سطح مكتب باستخدام WebView مدمج.

3. **الخادم المنفصل**: 
   - التطبيق الحالي **لا يتضمن** خادم ERPNext
   - يتصل بخادم ERPNext موجود مسبقاً (سحابي أو محلي)
   - يمكنك تغيير رابط الخادم في ملف `src/main.js`

## خطوات التحويل الكاملة

### الخيار 1: تطبيق سطح مكتب فقط (هذا المشروع)

**المميزات:**
- سهل التثبيت والاستخدام
- لا يحتاج موارد نظام كبيرة
- واجهة مألوفة كتطبيق سطح مكتب

**المتطلبات:**
- خادم ERPNext موجود (سحابي أو محلي)
- Node.js مثبت على جهازك

**الخطوات:**
```bash
cd erpnext-desktop-app
npm install
npm start          # للتجربة
npm run build      # لإنشاء ملف التثبيت
```

### الخيار 2: ERPNext كامل مع تطبيق سطح مكتب (متقدم)

إذا كنت تريد نظام ERPNext كاملاً يعمل محلياً على Windows:

#### أ. تثبيت WSL (Windows Subsystem for Linux)

1. افتح PowerShell كمسؤول ونفّذ:
```powershell
wsl --install
```

2. أعد تشغيل الكمبيوتر

3. ثبّت Ubuntu من Microsoft Store

#### ب. تثبيت ERPNext على WSL

اتبع الدليل الرسمي:
```bash
# داخل Ubuntu على WSL
wget https://raw.githubusercontent.com/frappe/bench/master/install.py
python3 install.py --production
```

#### ج. تكوين التطبيق للاتصال بالخادم المحلي

عدّل ملف `src/main.js`:
```javascript
const erpNextURL = 'http://localhost:8000';
```

#### د. بناء التطبيق

```bash
npm run build
```

## الفرق بين الحلول

| الميزة | تطبيق سطح مكتب فقط | ERPNext كامل محلي |
|--------|-------------------|-------------------|
| سهولة التثبيت | ⭐⭐⭐⭐⭐ | ⭐⭐ |
| استهلاك الموارد | قليل | عالي |
| يحتاج إنترنت | نعم (للنسخة السحابية) | لا (بعد التثبيت) |
| التحكم الكامل | لا | نعم |
| الصيانة | سهلة | معقدة |
| التكلفة | مجانية (+ اشتراك سحابي اختياري) | مجانية |

## التوصيات

### للشركات الصغيرة والمتوسطة:
استخدم **Frappe Cloud** مع تطبيق سطح المكتب:
- تكلفة معقولة
- صيانة سهلة
- تحديثات تلقائية
- دعم فني

### للشركات الكبيرة:
ثبّت **ERPNext محلياً** على خادم خاص:
- تحكم كامل في البيانات
- تخصيص متقدم
- تكامل مع أنظمة أخرى

### للمطورين والتجربة:
استخدم **WSL + تثبيت محلي**:
- بيئة تطوير كاملة
- اختبار التعديلات
- تعلم النظام

## حل المشاكل الشائعة

### 1. خطأ "npm not found"
```bash
# حمّل وثبّت Node.js من:
https://nodejs.org/
```

### 2. خطأ في الاتصال بالخادم
- تحقق من أن خادم ERPNext يعمل
- تأكد من صحة الرابط في `src/main.js`
- تحقق من جدار الحماية (Firewall)

### 3. التطبيق بطيء
- تحقّق من سرعة الإنترنت (للنسخة السحابية)
- قلّل عدد الوحدات المفعلة في ERPNext
- زِد ذاكرة RAM المخصصة

### 4. مشاكل في البناء (Build)
```bash
# امسح وأعد التثبيت
rm -rf node_modules
npm install
npm run build
```

## الأمان

⚠️ **ملاحظات أمنية مهمة:**

1. **للنسخة السحابية:**
   - استخدم HTTPS دائماً
   - فعّل المصادقة الثنائية (2FA)
   - استخدم كلمات مرور قوية

2. **للنسخة المحلية:**
   - لا تعرّض الخادم للإنترنت مباشرة
   - استخدم شبكة خاصة افتراضية (VPN) للوصول عن بُعد
   - حدّث النظام بانتظام

3. **للبيانات الحساسة:**
   - قم بنسخ احتياطي منتظم
   - شفّر قاعدة البيانات
   - اتبع أفضل ممارسات الأمان
